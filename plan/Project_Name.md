# Project Name --- QuickSee

## Product Identity

-   **Name:** QuickSee
-   **Short description:** A personal Web3 tracker for airdrops,
    whitelists, games, tokens, and release dates.
-   **Primary value proposition:** Paste once, organize quickly, and see
    what is coming next.
-   **Audience:** Individual Web3 participants tracking projects they
    have joined.
-   **Platform:** Responsive web app, designed for desktop, tablet, and
    mobile.
-   **Storage model:** Local-only for the MVP.
-   **Data collection:** Manual copy/paste from X; no automated X
    monitoring in MVP.
-   **Reminder model:** In-app reminders when the app is open.

## Core Product Rules

-   Never fabricate missing project information or dates.
-   Always show a review/edit step before saving parsed text.
-   Whitelist/Airdrop must be an explicit selection for Crypto Projects.
-   Keep unknown dates blank and distinguish confirmed from estimated
    dates.
-   Detect likely duplicates but let the user review the match.
-   Contract addresses must have a dedicated copy action.
-   Local-only data must never be described as synced or cloud-backed.
-   Make backup/export discoverable and explain local-data loss risks.
-   Do not start implementation until the client approves the project
    plan.
